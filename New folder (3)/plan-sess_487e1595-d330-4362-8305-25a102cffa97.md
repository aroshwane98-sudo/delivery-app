# پلانی نوێکردنەوە بەپێی تێبینییەکان

## ١. ماوەی نێوان بارەکان: 60 → 5 خولەک
- **`js/config.js`**: `CARGO_GAP_MINUTES` لە `60` بگۆڕە بۆ `5`.
- هەرچی دیکە (دوگمەی چاوەڕوانی و ژماردنەوە) لە `view-driver.js` بە ئۆتۆماتیکی ئەم نرخە بەکاردەهێنێت — گۆڕانکاری زیادە پێویست نییە.
- سنووری 3 بار لە ڕۆژێکدا وەک خۆی دەمێنێتەوە.

## ٢. خانەی ناوی بەکارهێنەر → لیست بۆکس (Listbox)
- **`index.html`**: خانەی `<input>`ـی ناوی بەکارهێنەر دەگۆڕدرێت بۆ `<select>` بە شوێنگرەوەی "هەڵبژێرە...".
- **`js/app.js`**:
  - فەنکشنی `initLoginAutocomplete` لادەبرێت و لە جیاتی ئەو، `initLoginSelect` دادەمەزرێت: لیستی بەکارهێنەران لە `usersv2` هێنراو و بە سێ گروپ ڕیز دەکرێت (سایەق / دابەشکار / مەندوب / بەریوبەر) بە `<optgroup>`.
  - `handleLogin`: ناونیشانی بەکارهێنەر لە dropdownـەوە دەخوێنرێتەوە و بەدواداچوونی پشکنینی تێپەڕەوشە وەک خۆی دەمێنێت.
- ئەمە هەڵبژاردن هەڵە لابەرێت (ناو بە دەستی نانووسرێت) و لەسەر مۆبایل باشترە.

## ٣. چارەسەری دووبارەبوونی لۆگین (ڕۆژانە)
- **`index.html` / `js/app.js`**: چەکبۆکسی "منی بیربکە" بە بنەڕەت **چالاک** (checked) بێت — واتە سێشن لە `localStorage` پاشەکەوت دەبێت و بەکارهێنەر ڕۆژانە دووبارە لۆگین ناکاتەوە، تەنها ئەگەر خۆی لاببات.

## ٤. پشتیوانی سێ فۆڕمەکە (سایەق / دابەشکار / مەندوب)
بەپێی هەڵبژاردنت ("تەنها ڕاپۆرتی فلتەرکراو"):
- **`js/view-reports.js`**: فلتەری ئۆتۆماتیکی بەپێی پیشە ئێستا هەیە (دابەشکار → تەنها تۆمارەکانی خۆی؛ مەندوب → هەمان شت). زیادکردنی بچووک:
  - نیشاندانی چippی ئاگادارکەرەوە لە سەرەوەی ڕاپۆرت بۆ دابەشکار/مەندوب/سایەق: "فلتەری خۆکار: تەنها تۆمارەکانی [ناو]" — بۆ ئەوەی بەکارهێنەر بزانێت بۆچی لیستەکە بەرەوڕاوە.
  - بۆ بەریوبەر: هیچ فلتەرێکی زۆرەملە نابێت (وەک خۆی).
- بەکارهێنەری دابەشکار/مەندوب دوای لۆگین ڕاستەوخۆ دەکەوێتە سەر تابی ڕاپۆرت (ئێستا ئەمە کار دەکات، تەنها پشتڕاست دەکرێتەوە).

## ٥. README نوێکردنەوە
- ڕوونکردنەوەی گۆڕانکارییەکان (5 خولەک، لیست بۆکس، remember-me بنەڕەت).

## تاقیکردنەوە (دوای جێبەجێکردن)
1. نوێکردنەوەی پەڕەکە لە وێبگەڕ و پاککردنەوەی کاش.
2. پشکنین: لیست بۆکسی ناوی بەکارهێنەر بە گروپەکانەوە کاردەکات.
3. تاقیکردنەوەی ڕەوتی شۆفێر: تۆمارکردنی بار، تەواوکردنی قۆناغەکان، پشکنینی ئەوەی دوای گەشتنەوە تەنها 5 خولەک ڕادەگیرێت.
4. لۆگین وەک دابەشکار و مەندوب: دڵنیابوون لە فلتەری خۆکار و ڕووتینی چippی ئاگادارکەرەوە.
5. دڵنیابوون لە پاشەکەوتی سێشن دوای داخستن و کردنەوەی پەڕەکە.
