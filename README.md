# سیستەمی گەیاندن 🚚

پلاتفۆرمێکی وێبی یەکگرتووە بۆ ڕێکخستن، بەدواداچوون و تۆمارکردنی پرۆسەکانی گەیاندن و کارەکانی شۆفێران، دابەشکاران و مەندوبەکان — بە ڕووکاری کوردی (Sorani)، مۆدی تاریک و ڕوون، و لە شێوازی PWA دامەزراندنی دەکرێت وەک ئەپڵیکەیشنی مۆبایل.

## تایبەتمەندییەکان

- **لۆگین بە لیست بۆکس**: ناوی بەکارهێنەر لە dropdown هەڵدەبژێردرێت (گروپکراو بەپێی پیشە: سایەق / دابەشکار / مەندوب / بەریوبەر) + تێپەڕەوشەی ٤ ژمارەیی.
- **منی بیربکە** بە بنەڕەت چالاکە — سێشن پاشەکەوت دەبێت و ڕۆژانە دووبارە لۆگین پێویست نییە.
- **فرە-بار ڕۆژانە**: شۆفێر دەتوانێت لە ڕۆژێکدا تا ٣ بار تۆمار بکات؛ دوای گەشتنەوەی هەر بارێک تەنها **٥ خولەک** چاوەڕوانیە (لە `CONFIG.CARGO_GAP_MINUTES` دەگۆڕدرێت).
- **سێ فۆڕمی پیشەیی**: سایەق (پانێلی قۆناغەکان)، دابەشکار و مەندوب (ڕاپۆرتی فلتەرکراوی خۆکار بۆ تۆمارەکانی خۆیان)، بەریوبەر (هەموو تۆمارەکان).
- **ڕاپۆرت**: فلتەری مەودای بەروار، گەڕان، کۆی خۆکار (کێش/پارچە/وەسڵ/پارە)، نوێبوونەوەی خۆکار.
- **ڕێکخستنەکان**: گۆڕینی تێپەڕەوشە، ئاڤاتار بە ئامرازی بڕین (زووم و پان)، گۆڕینی ڕەنگ و ڕووکاری تاریک/ڕوون.
- **PWA**: دامەزراندن وەک ئەپی مۆبایل + کاشی ئۆفلاین.

## شێوازی کارکردن (Run)

سیستەمەکە پێکهاتەیەکی تەواو جێگیرە (Static) — هیچ سێرڤەرێکی back-end پێویست نییە:

```bash
# ڕێگای ١ — بە پایتۆن
python -m http.server 8080
# پاشان لە وێبگەڕ: http://localhost:8080

# ڕێگای ٢ — بە Node
npx serve .

# ڕێگای ٣ — ڕاستەوخۆ فایلی index.html بکەرەوە بە وێبگەڕ
```

> تێبینی: بۆ دامەزراندنی وەک PWA پێویستە بە `http://localhost` یان `https` خزمەت بکرێت (سێرڤیسی وۆرکەر لەسەر `file://` کار ناکات).

## پێکهاتەی فایلەکان

```
index.html            — پەڕەی سەرەکی

js/config.js          — ڕێکخستنەکان: کلیدی Supabase، ماوەی نێوان بارەکان، ڕەنگەکان
js/api.js             — لایەری پەیوەندی بە Supabase (REST)
js/store.js           — سێشن، ڕووکار، کاشی لیستەکان
js/ui.js              — Toast، مۆدال، ئۆتۆکۆمپلیت، فۆرماتکردن
js/app.js             — دەستپێک، لۆگین، ڕاوتەری تابەکان
js/view-driver.js     — پانێلی شۆفێر (قۆناغەکان، فرە-بار، پارە)
js/view-reports.js    — ڕاپۆرت و ئامارەکان
js/view-settings.js   — ڕێکخستنەکان (تێپەڕەوشە، ئاڤاتار، ڕووکار)

sw.js                 — Service Worker (کاشی ئۆفلاین)
tools/make-icons.ps1  — سکریپتی دروستکردنی ئایکۆنەکان
```

## داتابەیسەکان (Supabase)

### پڕۆژەی ١ — تۆمارەکانی گەیاندن
خشتەی `delivery_records`:

| ستوون | جۆر | واتا |
|---|---|---|
| id | identity | ژمارەی تۆمار |
| driver | text | ناوی شۆفێر (بۆ باری دووەم/سێیەم پاشگری «دوو»/«سێ» دەکرێت) |
| distributor | text | ناوی دابەشکار |
| delegate | text | ناوی مەندوب |
| zone | text | ناوچە/زۆن |
| vehicle | text | ژمارەی سەیارە |
| cargo_weight | numeric | کێشی بار (کگم) |
| pieces_count | int | ژمارەی پارچەکان |
| receipt_number | int | ژمارەی وەسڵ |
| record_date / record_time | date/text | بەروار و کاتی دەرچوون |
| in_zone_time / out_zone_time / arrival_time | text | کاتی ناو زۆن / دەرێی زۆن / گەشتنەوە |
| collected_money | numeric | پارەی هێنراوە |

### پڕۆژەی ٢ — لیست بۆکسەکان
- `usersv2`: id, username, password (٤ ژمارە), profession (سایەق / دابەشکار / مەندوب / بەریوبەر), avatar_url (base64)
- `zonesv2`: id, name — لیستی زۆنەکان (٥٨ زۆن)

## ⚠️ کێشەیەکی ناسراوی داتابەیس — تریگەری شکاو

لە کاتی تاقیکردنەوەدا دەرکەوت کە هەر `UPDATE`ـێک لەسەر ستوونەکانی کات و پارەی
`delivery_records` ئەم هەڵەیە دەدات:

```
relation "public.driver_audit_logs" does not exist (42P01)
```

واتە تریگەرێکی UPDATE لەسەر خشتەکە هەیە کە دەیەوێت تۆمار بنێرێت بۆ خشتەیەک
بە ناوی `driver_audit_logs` کە **بەربووە**. بۆ چارەسەری، یەکێک لەمانە لە
SQL Editor ی Supabase جێبەجێ بکە:

```sql
-- ١) ناوی تریگەرەکە بدۆزە:
SELECT tgname FROM pg_trigger WHERE tgrelid = 'public.delivery_records'::regclass AND NOT tgisinternal;

-- ٢) یان تریگەرەکە دابمەزرێنە:
DROP TRIGGER IF EXISTS <ناوی_تریگەر> ON public.delivery_records;

-- ٣) یان خشتە نیەبووەکە دروست بکە (ئەگەر بە مەبەست بووە):
CREATE TABLE public.driver_audit_logs (
  id bigint generated always as identity primary key,
  record_id bigint,
  changed_at timestamptz default now(),
  old_row jsonb,
  new_row jsonb
);
```

**تا دەست بگات بە چارەسەرەکە:** سیستەمەکە بە خۆکاری چارەسەری لەبەرچاوگراوی
خۆی بەکاردەهێنێت — لە کاتی شکستدانی PATCH، تۆمارەکە بە نرخە نوێیەکان
دەسڕدرێتەوە و لەگەڵ زانیاری تەواوەکەی دووبارە تۆمار دەکرێت، بۆیە
سیستەمەکە بە ئاسایی کار دەکات.

## تەکنەلۆژیا

- **Frontend:** HTML5، CSS3، JavaScript (Vanilla، بێ فرەیموۆرک)
- **Backend:** Supabase (PostgREST) بە دوو پڕۆژەی جیا
- **Font:** Vazirmatn (گووگڵ فۆنتس)
- **PWA:** manifest + service worker + ئایکۆنەکان
